# Paw Fusion (UI-only prototype)
Frontend only: all data is mock/local. No backend, auth server or ML inference.

    npm install
    npx expo start      # scan the QR with Expo Go

Demo flow: Splash > Onboarding > Login ("Use demo account") > Home > Start Live Monitoring > simulated alerts/toasts > Stop > Session report > History / Alerts / Notifications.
